Plateforme de pilotage

Refonte de l'écosystème web HEP Vaud

Première installation : créez le compte administrateur. Saisissez le code d'installation : celui que vous avez indiqué dans la commande d'exécution (--code-installation=…), ou celui du fichier CODE-INSTALLATION.txt du dossier de données.

12 caractères minimum.

Activez la double authentification. Elle est obligatoire pour accéder à la plateforme. Installez une application d'authentification sur votre téléphone (Microsoft Authenticator, Google Authenticator, etc.), ajoutez un compte en scannant ce code, puis saisissez le code à 6 chiffres affiché.

Impossible de scanner ? Saisissez cette clé dans l'application :

Saisissez le code à 6 chiffres affiché dans votre application d'authentification. Sans votre téléphone, saisissez l'un de vos codes de secours.

Double authentification activée. Conservez ces 8 codes de secours en lieu sûr (gestionnaire de mots de passe, document imprimé). Chacun permet une seule connexion si vous n'avez pas votre téléphone. Ils ne seront plus affichés.
